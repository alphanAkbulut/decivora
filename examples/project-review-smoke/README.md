# Q14-A bağımsız proje incelemesi — sentetik fixture

[Kod, sınırlar, şema ve komutlar](../../docs/quality/project-review.md) · [Yerel sonuç](../../docs/quality/project-review-results.json).

- `context.fixture.json`: caller kontrollü test erişimi/current binding ve boş atomic group listesi. Gerçek hesap izni, IAM grant veya bağımlılık keşfi değildir.
- `mixed-response.json`: elle yazılan önceki valid örnekte Proje 2 criterion revision string yapılmıştır; gerçek model cevabı veya oracle değildir.
- `delayed-reply.fixture.json`: explicit clarification/soru/seçenek bağı ve source hash taşıyan insan test mesajı. Actor alanı production authority değildir.

Kaynak request [önceki frozen fixture](../receiver-smoke/request.json), valid review [bağımsız sentetik örnek](../receiver-contract/valid-review.json) olarak aynı kalır. Wrapper sadece review ve bekleme descriptor üretir; onay, komut, task kapanışı, UI teslimi veya model çağrısı yoktur. Kalıcı Inbox henüz uygulanmadı; descriptor/report dosyası runtime soru servisi sayılmaz.
